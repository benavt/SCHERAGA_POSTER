# Data availability and boundaries

Current analysis: 11,000 E. coli adenylate kinase predictions and 11,000 Mad2 monomer predictions, from 11 sampling methods. Bulk coordinates, matched refolds, per-residue arrays, score tables and immutable run evidence are kept outside Git and will be linked through two reviewed Zenodo resource records.

- Adk resource record: pending; no DOI assigned here.
- Mad2 resource record: pending; no DOI assigned here.

Do not treat placeholders as published depositions. Reference PDB models must remain separate from AIS counts and unscored for confidence. See [Zenodo handling](../zenodo/README.md), [study guide](../docs/SCHERAGA-study.md), and [reference catalog](../docs/SCHERAGA-references.md).
