# Physical poster

The authored physical poster accompanies the interactive webpage. The current validated export is **v014**, available locally as a 36 × 48 inch print PDF, smaller phone PDF, editable PPTX, PNG preview and verbatim abstract text. Both dataset concept DOIs are linked in the poster. These files have not yet been attached to a public GitHub release.

[Panel A](../docs/assets/SCHERAGA/Adk-poster-panel.png) and [panel B](../docs/assets/SCHERAGA/Mad2-poster-panel.png) are lightweight figure exports. PDF/PPTX bundles are managed outside Git. The [artifact inventory](../docs/SCHERAGA-downloads.json) records the current filenames, sizes and hashes; earlier download metadata is preserved under `docs/archive/`.

See [distribution status](../docs/distribution-status.md), the [typography guide](../docs/SCHERAGA-physical-typography.md) and [figure-style guide](../docs/SCHERAGA-physical-figure-style.md). The Adk dataset requires a corrected version even though its published concept DOI already resolves.
