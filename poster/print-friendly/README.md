# Compact physical poster for printing

[Download the compact print PDF (2.1 MB)](SCHERAGA_poster_36x48_print_compact_v014.pdf?raw=true).

This is a compressed copy of the final v014 physical poster for printers with file-size or memory limits. It is 2,087,975 bytes, 91.3% smaller than the 23,999,597-byte print master. The page remains **36 × 48 inches** with the same layout and all 56 clickable link regions.

The full-page image is reduced from 288 dpi to 120 dpi (4,320 × 5,760 pixels) and JPEG compressed. Small reference text, captions and plot labels were inspected in the rendered PDF. The [original final poster files](../final/README.md) remain unchanged and retain higher image resolution.

Choose the intended paper size in the printer dialog. Use actual size for a 36 × 48 inch poster, or fit to page for a smaller sheet.

The [manifest](manifest.json) records the source and output hashes, compression settings and checks. Verify the downloaded PDF with `sha256sum -c SHA256SUMS` from this directory. Authored poster content uses [CC BY 4.0](../../LICENSE-CONTENT.md); third-party material retains its own terms.
