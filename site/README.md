# Interactive poster

The virtual poster is a static HTML/CSS/JavaScript application with two target dashboards and an Abstract page. It shows synchronized observed-model movies, UMAP/PCA/t-SNE/Bonsai, experimental controls, confidence and measured similarity coloring.

Hosting deployment and a public URL remain separately reviewed. This seed does not copy private phone-preview services, private host bindings or full HTML/media payloads. Current display notes and source provenance are under `docs/`. No server-side PHP is required.
