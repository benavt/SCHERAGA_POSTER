# Historical deposition configuration templates

The two JSON files preserve metadata drafts imported with the initial source release. Their date/tag placeholders and generic asset paths are incomplete examples, not upload-ready configurations.

For new work, prepare a separate configuration using verified metadata and explicit file selections. See the [deposition guide](../README.md) and [package reference](../../docs/zenodo-deposition.md).

Both target records have published versions. The [resource availability page](../../docs/distribution-status.md) documents Adk v1's missing files and the need for a corrected version under its existing all-versions DOI. These templates do not establish present record contents or upload readiness.
